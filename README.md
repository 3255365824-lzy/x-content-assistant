# X 素材助手

原生 macOS 中文内容工作台，当前源码版本 **0.3.9（build 19）**。SwiftUI 界面、本机 Ollama 写作、Edge 只读采集；当前日常流程由用户在 X 页面最终发送。

本仓库保存源码、测试、应用图标与只读扩展，不包含个人素材、草稿、浏览记录、账号会话、配对令牌、运行数据库或本机服务备份。

## 功能

- **自拟灵感**：不需要原帖，按吃喝、消费、数码、旅行、社交和日常习惯生成轻观点。每组可选 1/5/10/20 条，默认 10 条上限；不合格时少生成、不凑数。
- **热门灵感**：读取已登录 Edge 的可见关注流，按新鲜度及可见互动筛选，使用本机模型加工为短帖。不是全 X 热榜，不保证获得爆款。
- **刷推互动**：优先查看较大账号，准备候选回复；已有文案和手动修改不被新采集覆盖。
- **本地编辑**：自动保存、收藏、可恢复归档、生成初稿恢复及创作台入口。
- **手动发送**：「去 X 回复／编辑发布」只打开预填文字页面；已处理／已交接不等于已公开发送。扩展不会发送、点赞或关注。
- **原有图文创作**：保留素材箱、卡片、排期、导出及发布历史界面；这些功能依赖独立的本地 Draft Engine/n8n 服务，见下文。

模型生成与本机复核均可能出错。文案是待审核候选，不保证事实正确、语言自然、完全原创或获得阅读量；医学及其他高风险内容必须另行核实。

## 环境

- Apple Silicon Mac、macOS 14 或更新版本。
- Swift 6 工具链和 macOS SDK（可使用 Xcode Command Line Tools）。
- [Ollama](https://ollama.com/) 及 `qwen3:8b`，默认仅连接 `127.0.0.1:11434`。
- Microsoft Edge：仅在采集新帖和交接至 X 时需要；自拟灵感无需 Edge。
- Node.js：仅运行扩展测试时需要，无第三方 npm 依赖。

```sh
ollama pull qwen3:8b
sh Scripts/test-app.sh
node --test EdgeExtension/tests/*.test.js
sh Scripts/package-app.sh
open 'dist/X 素材助手.app'
```

打包脚本构建 arm64、运行核心测试并使用本地 ad-hoc 签名验证，不自动安装、不公证，也不发布到 X 或 GitHub Releases。生成的 `.build/`、缓存、`dist/` 和 QA 产物均被 Git 忽略。macOS 若请求访问所在文件夹，请自行决定是否授权，不绕过系统保护。

打包时会将当前仓库的 `interaction-data/` 路径写入生成的 App 配置；扩展位于其相邻的 `EdgeExtension/`。移动 App 可以保留数据位置，但不要随意移动或删除仓库。如果克隆目录变化，应重新打包。直接 `swift run` 默认使用当前用户主目录下 `n8n-x-assistant/content-library/.state/interactions` 的后备位置，不会自动定位仓库扩展；日常使用建议按上面的打包方式启动。

## 第一次使用

### 自己写短帖

启动 Ollama → 打开 App → **素材箱 → 自拟灵感 → 自己写 10 条**。

选择话题和数量，等候本机生成及复核，挑选并编辑候选。单次生成由用户点击，不额外安装后台任务，也不自动公开发送。首批实测仍有生硬比喻和不合理细节；请把它当灵感起点，不要盲发。

### 读取 X 新帖

1. 在 Edge 的扩展管理页开启开发人员模式，选择「加载解压缩的扩展」，加载本仓库 `EdgeExtension/`。
2. 在 App 的「连接扩展」中复制短时连接码，仅粘贴到本扩展的连接窗口。
3. 在 Edge 自行登录 X，回 App 选择获取新帖／热门并加工。
4. 审核文案后点击去 X，在 X 页面核对账号并亲自发送。

扩展只解析已渲染的可见页面，不导出 Cookie、密码或登录会话。遇到登录、验证码或平台限制停止，不绕过。配对令牌只用于 `127.0.0.1:18796` 的本机连接，不是收费模型 token；不要上传连接码或运行目录。

## 独立本地服务与配置

本仓库是 App/扩展源码快照，**不包含独立的 Draft Engine、n8n 工作流、OrbStack 配置或模型权重**。自拟灵感与回复生成直接使用 Ollama；文件图文稿、信息卡和旧排期链路需要另行配置已有服务，不能只克隆本仓库就宣称全链路可用。

`RunConfiguration` 支持环境变量及生成的 Info.plist 配置：

| 配置 | 默认值 / 用途 |
| --- | --- |
| `XCONTENT_RUNTIME_ROOT` | 当前用户主目录下的 `n8n-x-assistant`，独立运行服务位置 |
| `XCONTENT_ENGINE_URL` | `http://127.0.0.1:8765`，独立 Draft Engine |
| `XCONTENT_N8N_URL` | `http://127.0.0.1:5678`，n8n |
| `XCONTENT_INTERACTIONS_ROOT` | 打包时设为当前仓库的 `interaction-data/` |

首页汇总了旧服务状态；旧服务离线的提醒不代表 Ollama 自拟生成不能使用。不要对公网暴露本地端口。

源码保留早期 OAuth/Keychain/X API 适配及模拟测试，但当前默认回复、热门和自拟短帖链路不依赖 X API。仓库没有 Client ID、密钥或令牌；历史执行桥的公开发送命令已禁用，不会启动 Codex 定时执行器。

## 验证范围

核心与 App 模型测试包含：旧数据兼容、请求去重、编辑保存、重启恢复、候选审核、状态保护、手动交接及网络错误模拟。测试不会产生真实 X 帖子。

0.3.9 原生 App 已验证一批真实本机生成、编辑自动保存、恢复初稿、进入创作台与正常重启后的数据保留。模型复核并非事实核查；用户的最终审核仍是必要环节。
